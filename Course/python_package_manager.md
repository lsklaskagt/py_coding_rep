# Day 20/30

PIP: стандартная система управления пакетами в Python, позволяющая устанавливать библиотеки из репозитория PyPI (Python Package Index), например numpy, pandas, scikit-learn, torch.

pip install package_name — скачать последнюю версию библиотеки.

pip install package_name==1.2.3 — скачать конкретную нужную версию.

pip uninstall package_name — удалить библиотеку.

pip freeze > requirements.txt — зафиксировать текущее состояние зависимостей в файл.

pip install -r requirements.txt — установить зависимости из готового файла.

Библиотеки в Python постоянно обновляются. Разработчики библиотек меняют сигнатуры функций, удаляют устаревшие методы или меняют логику вычислений.

Без фиксации версий: если ваш коллега или сервер выполнит команду pip install pandas, установится самая свежая версия на текущий момент. Если вы писали код на версии 1.5.0, а установилась 2.2.0, код может упасть с ошибкой из-за удалённых или изменённых функций.

С фиксацией версий: вы передаёте не просто список названий, а строгие соответствия вида pandas==2.2.1 и numpy==1.26.4. При установке pip возьмёт ровно эти версии, гарантируя одинаковую работу кода на любой машине.
