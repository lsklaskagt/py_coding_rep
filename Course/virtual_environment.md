# Day 23/30

По умолчанию пакеты через pip install ставятся глобально в систему. Если одному проекту нужна старая версия библиотеки, а другому — новая, возникает конфликт версий.

Виртуальное окружение создает изолированную директорию с собственной копией Python и локальной папкой для библиотек (site-packages).

Создать окружение можно через стандартный встроенный модуль Python (современный стандарт):

python3 -m venv venv
(где последнее слово venv — это имя создаваемой папки)

Активировать через source venv/bin/activate

Команда pip freeze сразу после активации покажет пустой список (в окружении ещё нет сторонних библиотек).
Установка пакетов (например, pip install Flask) скачивает их строго внутрь папки venv.
Экспорт зависимостей для переноса проекта: pip freeze > requirements.txt.

Выход из виртуального окружения в обычный системный режим через deactivate

Папку с виртуальным окружением (venv/) никогда не коммитят в репозиторий, так как она весит много и привязана к конкретной ОС. Её всегда добавляют в файл .gitignore.
